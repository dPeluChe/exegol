- [x] Timeout per task (`scheduled_tasks.timeout_minutes`, 1-1440, in the create/update schemas),

- [x] No overlap: a cron tick or Run now while the task has a queued or running run is dropped
- [x] A full concurrency slot leaves the run queued in the DB; it starts when a slot frees or on
  the next app start. A run left `running` by a quit is closed as failure ("Interrupted") and its
  agent, kept alive by the sidecar, is stopped; the scheduler now starts after sidecar recovery so
  that stop reaches the reattached PTY
- [x] Dependencies keep the old rule (a dependency whose last result is not `success`, a timeout
  included, blocks); a dependency still queued or running now makes the dependent wait instead of
