## 2026-10-01: a closed session no longer comes back as a black pin (branch `fix/pin-closed-session`)

- [x] Reported: close a pinned session in its project, go back to the Dashboard: the card is
  black with no Resume, and the project needs it closed again. The log shows why: the close
  removes the agent from the store and archives it in main, but a `syncFromDb` already on its
  way still listed it as live and re-added it (23:57:27 "2 added"), so the pin mirrored a dead

  closed session is unpinned (`unwatch`)
