## 2026-10-01: PTY sidecar batch, one SIDECAR_VERSION bump (branch `fix/sidecar-batch`)

Every item below waited for a `SIDECAR_VERSION` bump, which restarts every live terminal, so
they go together. `SIDECAR_VERSION` 1.4.0 → 1.5.0.

- [x] `session.clear` RPC (T166): the pane menu's Clear Terminal emptied only the view, so a
  reattach after an app restart replayed the cleared history from the ring buffer. Now it also
  clears the sidecar ring (an evicted one's file is emptied; the alternate-screen mode is kept so
  a cleared TUI still replays on the right screen) and main's headless emulator, which also
  rewrites the scrollback file. `terminal:clear` IPC → `PtyHost.clear` → `SidecarClient.clear`
- [x] The sidecar's hand-rolled, unbounded NDJSON reader now uses the shared `createNdjsonBuffer`
  (frame cap, multibyte-safe decoding). `createNdjsonBuffer` is linear: it carries a
  `searchFrom` offset instead of rescanning from 0 on every chunk
- [x] Unexported `EvictableSession`, `PendingState`, `AppendResult` (knip)
- [x] Memory pressure (T185.14, part): pending output is counted in UTF-8 bytes (the length the
  ring write already computed); `OutputGate` pauses every PTY while a client's socket queue is
  full and resumes on its `drain` (Node flow control: nothing dropped, the CLI blocks on its own
  writes). Eviction of active rings remains
- [x] T184.2 (DA1 half): while no client is connected, the sidecar answers a shell's DA1 query
  (`ESC[c` / `ESC[0c`) with xterm.js's reply, so fish does not wait ~10s. With the app open
  xterm answers; queries for a hidden pane and OSC 10/11/12 remain in TASK_TODO
- [x] T184.3: the reattach snapshot strips terminal queries (DSR, DA1/DA2/DA3, DECRQM, OSC
  10/11/12 `?`), so a new xterm does not answer old questions into the PTY. The ring keeps raw
  bytes and the live stream is unchanged
- [x] T184.4: before SIGTERM/SIGKILL of a previous sidecar pid, discovery checks with
  `ps -p <pid> -o command=` that the process still runs `pty-sidecar-entry`; a recycled pid is
  left alone (logged)
- [x] Simplify pass: `createNdjsonBuffer` moved to `lib/ndjson.ts` (the sidecar no longer bundles
  the MCP tool list; `exegol-protocol` re-exports it); dropping a slow client (no reconnect, so
  every terminal died) replaced by the pause above; `RingBuffer.clear()` always keeps the screen
  mode (its only caller); one `ps` check per stale kill; `PtyHost.clear` sends the Ctrl+L, so
  the renderer makes one call; `utf8Tail` shared with the headless snapshot cap, which could
  start mid-character; the bump file list lives only in the `SIDECAR_VERSION` comment
