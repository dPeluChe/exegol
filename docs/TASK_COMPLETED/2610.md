## 2026-10-01: a revealed terminal keeps its CLI's modes (branch `fix/terminal-scroll-after-switch`)

- [x] Reported: after moving between projects, the wheel stopped scrolling Claude in panes
  (rarer on pinned cards) until a window resize. A pane hidden for a while stops receiving
  output; when it shows again main repaints it with `ESC c` + the emulator snapshot, and the
  snapshot is serialized with `excludeModes`. ESC c turns every DEC mode off, so the mouse
  tracking Claude uses for the wheel (1000/1006), bracketed paste (2004) and cursor keys stayed
  off until a resize made Claude redraw and send them again. The emulator already tracked the
  modes: `modeSequence()` turns them back into sequences, and `getLiveSnapshot` (the reveal
  repaint and `terminal:get-snapshot`, so an app restart and the dormant resync too) appends
  them. Read-only scrollback keeps the plain snapshot (a dead session must not track the mouse)
