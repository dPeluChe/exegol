## 2026-09-23: T194 Dashboard watch list with interactive mirrors (branch `feat/t194-overview-watch`)

Pin sessions from any project and work on them in parallel from the Dashboard without switching
folders. Each pinned session is a live, interactive mirror of its terminal.

**Dashboard**
- [x] Its own view (`activeView: "dashboard"`) overlaying the workspace: no project is highlighted,
  panes stay mounted at the same size behind it, picking a project lands on its Agents tab
- [x] With sessions pinned it shows only Watching; "Show all agents" reveals the fleet groups
- [x] Empty state offers "Start agent" per project; header says "All projects"
- [x] One `jumpToAgent` for dashboard, sidebar, hotkeys and toasts; `switchSection` leaves the
  dashboard; sidebar attention cards use the session name and aren't repeated per project

**Watching**
- [x] "Watch" toggle on dashboard cards and the terminal toolbar; global, persisted list that
  follows a session across resume (`replaceAgent`)
- [x] Full-height cards, 1-3 per row; collapsed sessions are vertical strips in their row; drag
  strips or card headers to reorder; up to 6 open; a session needing input opens in place
- [x] Wheel over an unfocused mirror scrolls the dashboard; click the mirror to scroll its history

**Mirror mode** (`TerminalInstance mirror`)
- [x] Types into the session but never resizes the PTY, never answers terminal queries, writes no
  pane state; replies (CPR, DA, DSR, DECRPM, OSC/DCS, focus) are filtered (`mirror-input.ts`)
- [x] Renders at the PTY grid (`terminal:get-size` before the snapshot, then `terminal:resized`)
  and fits its font to both dimensions; the rule always terminates (tested over ~7000 card sizes).
  One fit in flight per terminal; canvas renderer (no WebGL context each)

**Terminal sizing and repaint** (found with dev-only `[TermDbg]` logs, since removed)
- [x] Alt-screen fit CEILED rows and relied on a line-height squeeze that never applied (T193.23):
  each fit overflowed the box by a row, the box grew and the PTY kept gaining rows (234x70 →
  240x78 idle), with Claude's input box below the edge. Always the floored fit; `terminal-fit.ts`
  removed; `min-h-0` on the pane box so its height comes from layout
- [x] Mirror font fit flip-flopped between two sizes forever (glyph rounding), rebuilding xterm's
  atlas every frame (50-110ms rAF violations)
- [x] No PTY resize before layout (was 80x24); resizes coalesced (80ms); main drops same-size
  resizes; a size sent before reattach is kept and applied (`PtyHost.pendingSizes`)
- [x] `terminal:redraw`: main jiggles the PTY without telling mirrors; the mount kick runs only for
  alt-screen sessions and once per session (a project switch used to cost two redraws per pane)
- [x] Visibility per view (`windowId:viewId`): a pane unmounting no longer silenced its mirror;
  a view's first report skips the RIS repaint; WebGL detach debounced

**Other**
- [x] Resume with nothing to continue (`claude --continue` in a fresh folder exits 1) starts a
  clean session: `hasLocalSession` asks the CLI's history adapter first (90-day window)
- [x] `bun run kill:dev` stops a stuck dev Electron without touching the sidecar

## 2026-09-22: v0.5.0 pre-build audit (branch `release/v0.5.0`)

first run with migrations applied to empty/pre-w3_009/live DBs, tech debt) before cutting the DMG.
Fixed here; open items are T193 on the board.

  in the packaged app. Now imports `coreRust` from `agents/spawn-env` (`ipc/procedures/oplog.ts`)

  `extraResources` → `tray-icon.png` (`system/tray.ts`, `electron-builder.ts`)

- [x] Version 0.5.0 (`apps/desktop/package.json`, CHANGELOG, RELEASE)

  flag, so a queued `agent_send` could type into the dialog and confirm it with Enter. Now only
  leaving `waiting_input` clears it (`spawn-env.ts#broadcastAgentStatus`)
- [x] Oplog v1 undo force-checked-out `project.path`: refuses when the tree is dirty, when HEAD
  moved past the entry, for `worktree_create`, and for agents that ran in a worktree. Undo and
  snapshot restore errors show a toast
- [x] A worktree shared by two agents is not removed while another live agent uses it
- [x] Commit only removes an `index.lock` older than 60s (a live agent git op holds a fresh one)
- [x] `files.delete` refuses a project root, `~/.exegol` and `.git`
- [x] Removing a project asks for confirmation and stops its live agents first
- [x] Skills migration copied legacy skills only when canonical was empty, then deleted the legacy
  dir anyway; now copies every missing skill (`skills/paths.ts`)
- [x] An unparsable `~/.codex/hooks.json` is left alone instead of overwritten; `~/.codex` not
  created when Codex isn't installed
- [x] The MCP socket is unlinked only by the instance that owns it (dev beside packaged)

### Lifecycle and pipelines
- [x] Reverted the main-side status dedup from the readiness PR: title/session broadcasts moved the
  key without a DB write, so the DB could stay stale. The renderer no-op check stays
- [x] Resume keeps the agent's access mode
- [x] crush/opencode/kiro keep scrollback (collected before the parse skip), so `final_output` and
  scoring have text
- [x] Pausing a pipeline held nothing: the killed step's exit advanced the run. Paused runs ignore it
- [x] Pipelines take a task (textarea); `{{task}}` used to be the template name

### Environment and settings
- [x] The login-shell PATH is adopted into `process.env.PATH`, so main's own `gh`/`git` find
  Homebrew when launched from Finder; a shell timeout falls back to Homebrew dirs; `gh` misses are
  not cached
- [x] Diff cache has a 5s TTL (agent edits never went through an invalidating mutation)
- [x] Settings auto-save sends only the changed fields (the mount-time form reverted MCP verbose
  and notification mutes)
