## 2026-09-23: T194 Overview watch list with interactive mirrors (branch `feat/t194-overview-watch`)

Pin sessions from any project to the top of Overview and work on them in parallel without switching
folders. Each pinned session is a live, interactive mirror of its terminal.

- [x] "Watch" toggle on Overview cards and in the terminal pane toolbar; the list is global,
  persisted (`stores/watch.ts`), and follows a session across resume (`replaceAgent`)
- [x] Watching section (`sections/WatchingSection.tsx`): project chip, status, attention badge,
  Open (jump to project + pane), unwatch; 1 or 2 columns; needs-input first
- [x] A session that asks a question opens its mirror on its own; focusing it keeps it open and
  clears the badge. At most 4 mirrors open (each is a WebGL xterm)
- [x] Mirror mode in `TerminalInstance` (`mirror` prop): types into the session but never resizes
  the PTY, never answers terminal queries, and writes no pane state
- [x] Terminal replies (CPR, DA, DSR, DECRPM, OSC/DCS, focus) are filtered from mirror input
  (`mirror-input.ts`, tested): with the owning pane open, the agent would otherwise get each reply
  twice, plus replies to old queries replayed from the snapshot
- [x] Mirrors render at the PTY's real grid and shrink the font to fit (`fitMirror`), so output
  wraps exactly as in the pane. New IPC: `terminal:get-size`, `terminal:resized` broadcast from the
  owner's resizes; size is applied before the snapshot is written
- [x] Pane grid feedback loop (found with the dev-only `[TermDbg]` logs): the alt-screen fit
  CEILED rows and meant to squeeze the line height, but the squeeze was a no-op (T193.23), so each
  fit left the grid one row taller than its box, the box grew, and the PTY kept gaining rows
  (234x70 → 240x78 at idle) with Claude's input box below the visible edge. Always the addon's
  floored fit now; `terminal-fit.ts` removed; the pane container clips
- [x] Mirror font fit terminates (hysteresis, one fit in flight, width-only refit); mirrors draw on
  canvas; WebGL detach debounced; per-view visibility in main (`windowId:viewId`)
- [x] `bun run kill:dev` stops a stuck dev Electron without touching the sidecar
